<h1>RDP Trust Script:</h1>

Creates and applies certificates to RDP connection files, converting them into trusted connections for secure remote access.
<br>

## ▶️ Run this command in an Administrative Powershell 
<br>
⚠️ **Warning:** This command downloads and executes a remote script
<br><br>

```powershell
iwr bit.ly/GetRDPTrust| iex
